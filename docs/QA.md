# TopoOpt Quality Assurance & Verification Checklist

This document provides the formal QA test matrix covering functional workflows, numerical accuracy, input hardening, fault tolerance, HiDPI scaling, and accessibility.

## QA Verification Matrix

| ID | Test Scenario | Steps | Expected Result | Linux Status | Windows Status |
|:---|:---|:---|:---|:---:|:---:|

Inspect bounding box heuristic prompt. | Unit guard modal triggers for dimensions $< 1\text{ mm}$ or $> 2000\text{ mm}$; user can accept or rescale (m, in, mm). | **PASS** (Verified via `StlReaderWriterTests`) | **PASS** (Ready) |
| **QA-02** | **Boundary Condition Management** | 1. Add Load, Support, and Preserve regions.<br>2. Select triangles via flood-fill.<br>3.
